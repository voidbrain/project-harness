The optional launcher registers a private job before the supplied executable runs and passes its job/store identity. A neutral subprocess fixture establishes this order and preserves failed exits; it is not live client instruction-loading evidence. Parent jobs must be open and belong to the same repository. Child source events remain independently deduplicated; parent spend is not copied into children. A launcher does not stop a host from starting an agent another way, prove instruction compliance, change permissions or install a startup hook. No model invocation was used for this acceptance.

Selected adapters consume explicitly supplied metadata-only exports, not native transcript files. Exporters belong to the host/client owner and must retain original IDs and final per-request counters; they must not add job prefixes that allow one request to be imported repeatedly. Codex turn records have no native turn ID in the documented completion example, so stable exporter identity is required. Claude message IDs supply the event identity directly. Shared multi-step model turns remain unallocated unless explicit conserving attribution exists. Unknown model, cache-write or reasoning counts remain null. No discovered source in this run establishes actual priced session spend; optional price/batch guidance therefore remains unavailable, not inferred. Effectiveness and estimate comparisons are T03.
