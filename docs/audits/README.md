# Audits

One file per audit, named `<YYYY-MM-DD>.md` (a suffix is allowed: `<date>-<topic>.md`). The newest file is the current audit; `npm run check:freshness` warns when it is more than 7 days old.

An audit records, for what changed since the previous one: what was checked (docs, tests, template text, tools, procedure, the projects that apply it, CI), how, the result with evidence, and the backlog records it opened or updated. It is dated evidence, never rewritten later.
