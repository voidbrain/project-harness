# Procedure discovery index

This index links authoritative procedures; it does not duplicate or replace them. AGENTS and its safety/permission rules load first. Read every applicable procedure before its task; a short index never defers requirements. Project area notes and style guidance remain binding. Links are discovery aids, not proof of performed work.

| Trigger | Authority | Expected output/evidence |
|---|---|---|
| Session start | AGENTS.md; harness freshness | Actual main/CI, selected integrations/context, current blockers |
| Update, close or sequence records | [Backlog rules](../BACKLOG-RULES.md) | Owned records, dated acceptance, dependencies and regenerated views |
| Adopt task sources, parallel ownership or model profiles | [Parallel work](parallel-work.md) | Explicit tasks/resources, shared claim evidence and reviewed model suitability |
| Reconsider design, assumptions or alternatives | [Architecture reassessment](architecture-review.md) | Revision-scoped review, retained/superseded decisions and owned findings |
| Run a full/scoped audit | [Audit procedure](audit.md) | Dated report/scope manifest across the named areas, exclusions and findings |
| Change a source with derived outputs | [Change impact](change-impact.md) | Regenerated affected outputs or an owned justified deferral |
| Select local/CI verification | [Verification selection](verification.md) | Affected checks and actual evidence; full checks when required |
| Change tests/coverage | [Coverage guide](coverage-guide.md) | Meaningful assertion/coverage scope, separate browser/device limits |
| Reconcile/review governing rules | [Maintenance guidance](maintenance.md) | Requirement-preserving review, measurements and tested outcomes |
| Set up/change stack or use MCP | [MCP guidance](mcp.md) | Useful capabilities, actual connection state and authorized setup |
| Coordinate repositories | [Solution profile](solution-profile.md) | One-way ownership/dependencies and source-revision-qualified evidence |
| Add/use a shared skill | [Skill guidance](skills.md) | Reviewed source, permissions, limits and actual host discovery |

Projects extend their AGENTS procedure table/area notes with project-specific commands and guides, linking this index rather than creating competing copies of its procedures. Architecture describes current/intended boundaries; decisions own rationale/alternatives; roadmap owns outcome sequencing; backlog/task sources own executable work/status; acceptance and audit reports own dated evidence. Validators check declared structure, not the truth of free text, architectural merit or model competence.
