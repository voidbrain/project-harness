# The mistaken v10.12.0 tag, 2026-11-25

**Status: waiting on the owner's decision.**

What happened: the agent ran the release commands for 10.12.0 (F-095-T02) in one chain after `merge-when-green.mjs 265`. The merge failed (a missing maintenance receipt), but a pipe hid the failing exit status, so the chain went on: it tagged `v10.12.0` on the old `main` `0125a12` (10.11.3 content), pushed the tag and published its Release. It did not move or delete the tag: that is asked first.

Effect: a project that reconciles to `v10.12.0` gets 10.11.3 files under a 10.12.0 name; `check-harness` compares copied files with that tag.
